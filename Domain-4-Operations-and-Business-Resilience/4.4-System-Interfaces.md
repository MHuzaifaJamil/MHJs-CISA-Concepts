# 4.4 System Interfaces

> **Markers:** 📓 = in my Google Doc notes · ⭐ = frequently tested · ➕ = not in the review manual, verify · unmarked = gap to study. Numbering follows the ISACA CISA Review Manual 28th Ed.

- Interfaces pass output of one application as input to another with little human interaction
- Work across different languages and developers
- Transfer categories
  - System-to-system: internal or external; financial data, analytics and BI
  - Partner-to-partner: partners interface directly, e.g., supply chain
  - Person-to-person: email attachments, shared drives; hardest to control
### 4.4.1 Risk associated with system interfaces
- System-to-system problems cause pervasive errors
- Partner-to-partner exposes confidential data and partner cyber vulnerabilities
- Person-to-person: human error, security exposure, privacy issues
- Inaccurate reports harm decisions and create compliance liability
- Extracted data must equal data recorded in recipient
- Unauthorized access via interception, phishing, wrong shared-drive access, insecure third parties
- Outages produce incomplete reports
### 4.4.2 Controls associated with system interfaces
- Program tracks all internal and external interfaces and transfers, including ad hoc
- Program capabilities
  - Manage multiple transfer mechanisms and protocols, or APIs
  - Encrypt, decrypt, electronically sign files and API calls
  - Compress/decompress; connect to database servers; email transfers
  - Automate regular transfers; interruption handling
  - Analyze, track, report data attributes; regulatory compliance
  - Integrate with back-office applications; authenticate and authorize users; log events
- Reconciliation of sent versus received data
  - Automated controls preferred; manual report comparison; cryptographic hash checksums
  - Monitored by qualified person
- Encryption when interception risk is high
- Nonrepudiation of recipient
- Audit trail: sender, send time, receive time, data format, method, recipient
- Assess server logs along transfer path
- External market data feeds need strict inbound authentication 📓⭐
  - Missing authentication is more critical than missing encryption or quality monitoring 📓
