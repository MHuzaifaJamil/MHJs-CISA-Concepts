# 4.2 IT Asset Management

> **Markers:** 📓 = in my Google Doc notes · ⭐ = frequently tested · ➕ = not in the review manual, verify · unmarked = gap to study. Numbering follows the ISACA CISA Review Manual 28th Ed.

- Asset: tangible or intangible value (people, information, infrastructure, finances, reputation)
- First steps: identify all IT assets and build inventory
- Inventory record per information asset
  - Owner
  - Designated custodian
  - Specific identification
  - Relative value
  - Loss implications and recovery priority
  - Location
  - Security/risk classification
  - Asset group
  - Life cycle management stage
  - Compliance requirements
  - Access controls
  - Disposal date
- Building initial inventory
  - Purchasing system
  - Contracts
  - Installed software review and discovery tools
- Maintaining inventory
  - Add new assets; periodically confirm possession; remove returned/destroyed
  - Physical tagging of hardware
  - Software tracked by network scanning and annual license confirmation
  - Remote wipe or disable on departure, loss, or theft
- Software audits flag unapproved software; restrict installation to IT admins
