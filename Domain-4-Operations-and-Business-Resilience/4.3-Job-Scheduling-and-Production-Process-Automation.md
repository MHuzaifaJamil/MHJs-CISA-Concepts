# 4.3 Job Scheduling and Production Process Automation

> **Markers:** 📓 = in my Google Doc notes · ⭐ = frequently tested · ➕ = not in the review manual, verify · unmarked = gap to study. Numbering follows the ISACA CISA Review Manual 28th Ed.

- Job schedule lists jobs, run order, dependencies, conditions for execution
- Schedules batch jobs, backups, maintenance
- High-priority jobs get optimal resources; maintenance in nonpeak times
- Low-priority jobs run when time is available
- Continuous availability makes scheduling harder
### 4.3.1 Job scheduling software
- System software for installations processing many batch routines
- Sets daily work schedules; automatically determines jobs to submit
- Needs ongoing maintenance and optimization
- Advantages
  - Job information set up once; less operator reliance and error
  - Job dependencies defined; failed job blocks dependent jobs
  - Logs of all job successes and failures
  - Security over access to production data
  - Less or no manual task burden
### 4.3.2 Scheduling reviews
- Checkpoints in production jobs are detective controls 📓
- Regularly scheduled applications
  - Input deadlines, data preparation time, estimated processing time, output deadlines
  - Included in SLAs and functioning per SLAs
  - Critical applications identified and given highest priority
- Job schedule
  - Rush and rerun jobs scheduled consistent with priority
  - Procedures optimize resources while meeting service needs
  - Operators record jobs and required data files
- Daily job schedule
  - Adequate personnel per shift
  - Serves as audit trail; passes work statement to next shift
- Console log
  - Jobs completed as scheduled
  - Failures flagged, communicated, root causes investigated
- Exception processing logs
  - Written/electronic owner approval for request-only jobs
  - Operators record and review exception requests
- Restarting jobs
  - Authorized, logged, management reviewed
  - Correct input files used on rerun; completion verified
- Personnel
  - Only authorized staff may change schedules and priorities
