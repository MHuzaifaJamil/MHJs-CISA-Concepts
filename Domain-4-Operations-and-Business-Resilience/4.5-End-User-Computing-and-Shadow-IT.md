# 4.5 End-User Computing and Shadow IT

> **Markers:** 📓 = in my Google Doc notes · ⭐ = frequently tested · ➕ = not in the review manual, verify · unmarked = gap to study. Numbering follows the ISACA CISA Review Manual 28th Ed.

- EUC: non-IT users create and manage technical resources
- Shadow IT: resources acquired outside official process, IT unaware
### 4.5.1 End-user computing
- Users design own applications with software products
- End-user support manager liaises between IT and users
- Benefits: fast deployment, flexibility, relieves IT
- Risk: no independent review, no formal development methodology
- Security risks
  - Authorization missing
  - Authentication missing
  - Audit logging unavailable (Excel, Access)
  - Unencrypted sensitive data
  - Data loss: no backups
  - Compliance risk
  - Not in IT inventory, hindering monitoring
  - Excluded from maintenance and patching
- Controls
  - Management defines risk criteria for criticality
  - EUC use policies
  - Data classification and inventory of EUC applications
  - Critical EUC applications get same controls as others
### 4.5.2 Shadow IT
- Systems or software used without IT/cybersecurity vetting and approval
- Drivers: low-cost cloud software, smartphones, home networks, personal hardware
- Disruption and innovation but significant risk
- Manage by identifying upgrade/digitalization need, determining controls, reassessing regularly
- Typical controls
  - Shadow IT policy aligned with business objectives
  - IT as service-delivery organization, consultative
  - IT budgeting and procurement approval
  - IT system consolidation to reduce footprint
  - Explicit user access and administrative rights
  - User education program
  - User activity monitoring
  - User data exchange: strong endpoint controls
