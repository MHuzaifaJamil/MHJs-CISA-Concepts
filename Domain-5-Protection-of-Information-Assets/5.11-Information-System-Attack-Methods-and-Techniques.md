# 5.11 Information System Attack Methods and Techniques

> **Markers:** 📓 = in my Google Doc notes · ⭐ = frequently tested · ➕ = not in the review manual, verify · unmarked = gap to study. Numbering follows the ISACA CISA Review Manual 28th Ed.

### 5.11.1 Fraud risk factors
- Fraud triangle (Cressey)
  - Motivation: perceived financial or other need
  - Rationalization: self-justification
  - Opportunity: organizations control this most
- Controls limiting opportunity: logical access, SoD, HR security
### 5.11.2 Computer crime issues and exposures
- Threats to business
  - Financial loss
  - Legal repercussions
  - Loss of credibility or competitive edge
  - Blackmail, industrial espionage, organized crime
  - Disclosure of confidential or embarrassing information
  - Sabotage; hacktivism
- Possible perpetrators
  - Hackers
  - Crackers
  - Script kiddies
  - Employees
  - IT personnel
  - End users
  - Former employees
  - Nations
  - Competitors, terrorists, organized criminals, phreakers
  - Part-time and temporary personnel
  - Third parties
  - Opportunists
  - Accidental unaware
- Computer crime categories (Figure 5.57)
  - Computer is target
  - Computer is subject
  - Computer is tool
  - Computer symbolizes crime
- Social engineering (phone pretexting) 📓
  - Impersonation by phone, dumpster diving, shoulder surfing
  - Best defense: ongoing awareness program
- Common attack methods (Figure 5.58)
  - Alteration attack: cryptographic hash is primary defense
  - Botnets: zombie computers
  - DoS: ICMP flood, smurf, ping flood, SYN flood, teardrop
  - DoS: peer-to-peer attack, permanent DoS (phlashing)
  - DoS: buffer overflow, bandwidth-saturating flood, banana attack
  - DoS: pulsing zombie, nuke, reflected attack, unintentional attack
  - Distributed DoS (DDoS)
  - Eavesdropping
  - Phishing: spear phishing, whaling, smishing, vishing
  - Flooding
  - Interrupt attack
  - Juice jacking: public USB charging ports
  - Malicious code: Trojan horses
  - Malicious code: logic bomb; honey tokens as pseudo flaws
  - Malicious code: trap doors (back doors)
  - Man-in-the-middle attack
  - Masquerading: IP spoofing
  - Message modification
  - Network analysis: footprinting, port scanning
    - Intruder builds profile: aliases, internal addresses, gateways, firewalls
  - Packet replay
    - Passive capture, then active reinsertion into the network
    - Effective when the receiving end is automated
  - Pharming: DNS poisoning; antipharming needed
    - Alters hosts file or exploits DNS server software
    - Antivirus and spyware removal cannot stop pharming
  - Piggybacking: physical access exposure
    - Following authorized person through door, or tapping authorized telecom link
  - Race conditions (TOC/TOU)
    - Exposure grows with time gap between check and use
    - Causes: nonatomic sequence by untrusted processes; deadlock or locking failure
    - Careful programming and good administration reduce them
  - Remote maintenance tools
    - Poorly secured tools let hackers gain elevated access remotely
  - Resource enumeration and browsing
    - Enumeration lists names, directories, privileges, shares, policies
    - Browsing is manual enumeration aided by commands and tools
  - Salami technique vs rounding down
  - Injection attack (SQL)
  - Zero-day exploit: patching, sandboxing, IRP
  - Cryptojacking: monitor CPU usage
  - Cross-site scripting (XSS): input validation and sanitization
  - Cross-site request forgery (CSRF)
    - Forces authenticated victim into unwanted actions, often via link
    - Administrative victim can compromise the whole web application
  - DNS tunneling
    - Hides malware in DNS queries; creates persistent channel firewalls miss
    - Defenses: block malicious DNS, denylist exfiltration destinations, analyze queries
  - URL poisoning (URL interpretation): MFA
    - Attacker alters or guesses URLs to reach admin or back-end pages
  - DNS spoofing
    - Altered DNS records send victims to a fake website
    - Keep DNS servers up to date
  - Traffic analysis
    - Inference attack on communication patterns, used when messages are encrypted
  - Unauthorized access through Internet or web services
  - Viruses, worms, spyware
### 5.11.3 Internet threats and security
- IP gives no delivery proof or address verification
- Network security threats
  - Probing network information leads to active attacks
- Passive attacks
  - Network analysis
  - Eavesdropping
  - Traffic analysis
- Active attacks
  - Brute-force attack
  - Masquerading
  - Packet replay
  - Phishing
  - Message modification
  - Unauthorized access through Internet
  - DoS
  - Remote access penetration attacks
  - Email bombing and spamming
  - Email spoofing
  - Affect integrity, availability, authentication
- Causal factors for Internet attacks
  - Freely available tools: nmap, netcat, strobe
  - Password crackers: John the Ripper, L0phtCrack
  - Lack of awareness and training
  - Unpatched known vulnerabilities
  - Inadequate firewall and host OS security
- Targeted attacks
  - Multilevel attacks via custom malware and back door
  - Egress monitoring, dummy accounts as indicators
  - Preventive: baselining, hardening, exception monitoring, endpoint controls
- The OWASP Top 10
  - Ten most common and impactful web application vulnerabilities
### 5.11.4 Malware
- Attacks executables, file directory, boot areas, data files
- Types: ransomware, worms, viruses, adware, spyware, rootkits
- Worm does not attach to programs
- Virus and worm controls
  - Preventive (policy) and detective (technical) both needed
  - Vendor demos on own machines
  - Scan shareware and new software
  - Technicians scan disks on test machine
  - Antimalware on workstations and servers
  - Authentic bridge, router, gateway updates
  - Scan backups once malware detected
  - Educate users; yearly policy review
  - Eradication procedure and incident procedures
- Management procedural controls
  - Build from clean master copies
  - Scan media on standalone machine
  - Update signatures frequently
  - Protect removable media
- Technical controls
  - Boot malware protection (firmware)
  - Remote booting
  - Hardware-based password
  - Block insecure protocols at firewall
  - Scanners: malware masks/signatures
  - Scanners: heuristic scanners (high false positives)
  - Active monitors
  - Integrity CRC checkers
  - Behavior blockers
  - Immunizers
  - Eradication programs and inoculators
- Antimalware software implementation strategies
  - Scheduled scans
  - On-demand scans
  - Continuous on-the-fly scanning
  - Malware walls: SMTP, HTTP, FTP protection
  - Scanner features: reliability, resident memory, efficiency
### 5.11.5 Ransomware
- Encrypts data and demands ransom; WannaCry, Maze
- Double extortion: also threatens data release
- Three stages: access via phishing, asymmetric encryption, ransom demand
- Best practices
  - Secure networks, VPN
  - Continuous data backups
  - Secure (immutable) backups
  - Effective patch management
  - Strong authentication (RDP)
  - Minimal attack surface
  - Antiransomware solution
- Mitigating active ransomware infections
  - Quarantine the machine
  - Contain the spread
  - Do not switch off system: preserve volatile memory
  - Create backup of encrypted files
  - Check for decryptors
  - Locate patient zero
  - Wipe and restore from clean backup
  - Report to authorities
- Ethical considerations for ransomware
  - Law enforcement urges not paying
  - Cost-benefit analysis in practice
  - Downside: no key or key fails
