# 5.7 Public Key Infrastructure (PKI)

> **Markers:** 📓 = in my Google Doc notes · ⭐ = frequently tested · ➕ = not in the review manual, verify · unmarked = gap to study. Numbering follows the ISACA CISA Review Manual 28th Ed.

- PKI: policies, procedures, hardware, software, people for certificates
### 5.7.1 Digital certificates
- Certificate authority (CA) signs certificate binding public key to owner
- Certificate policy (CP): actors, roles, key generation, name selection
- Certificate practice statement (CPS)
  - Certificate types issued
  - Issuing, renewing, recovering policies
  - Cryptographic algorithms and key length
  - Certificate lifetime
  - Revocation and CRL policies
- Registration authority (RA) functions
  - Verify subject information
  - Verify right to requested attributes
  - Proof of possession of private key
  - Report key compromise
  - Assign names
  - Generate shared secrets
  - Initiate registration with CA
  - Initiate key recovery
  - Distribute physical tokens such as smart cards
### 5.7.2 Key management
- Key creation (generation)
- Key distribution
- Key storage and custody
  - Dual custody and split knowledge
  - Key escrow
- Key rotation
- Key recovery and backup
- Key destruction
  - States: suspended, revoked, expired, destroyed
### 5.7.3 Certificate revocation
- Terminates certificate before expiration
- Reasons
  - Change in affiliation
  - Compromise of private key
  - Cessation of operation
  - Superseded
  - Unspecified: not recommended
  - CA compromise
- Revoked CA invalidates all certificates below it
### 5.7.4 Certificate Revocation List (CRL)
- List of certificates revoked before expiry
- Published at CRL distribution point (CDP)
- Revocation states: revoked (irreversible) and hold (reversible)
- CRL contents
  - Issuer name
  - Revocation date and time
  - Reasons
  - Extensions
  - Signature algorithm
  - Certificate serial number
  - Next CRL issue date
- Online Certificate Status Protocol (OCSP)
  - Real-time status: valid, revoked or unknown
  - OCSP stapling: web server attaches cached response
  - Stapling improves performance and user privacy
### 5.7.5 PKI infrastructure risk
- No clear key renewal and revocation policy is the biggest concern 📓⭐
- Outdated protocols
- Weak keys under 2,048 bits
- Infrequent key rotation
- Mismanaged certificates, expired certificates
- Lack of automation
- Insufficient skills and resources
- Unclear certificate ownership
- Lack of policies
- Limited visibility
- Poor private key management
- Compromised root CA: store offline in vault
- Poor patch management
### 5.7.6 Audit procedures for PKI
- CA audit
  - Security policy, physical controls
  - Personnel background checks
  - Audit log backups
  - Key management life cycle
  - Isolated CA systems
- RA audit
  - Enrollment per CPS
  - Role limited to submitting details
  - Onboarding and termination procedures
  - Secure CA-RA channels
  - Activity logging
  - MFA for RA access
  - Prior audit reports and violations
- Certificate audit
  - Information published on CA website
  - Renewal, suspension, revocation per CPS
  - Secure distribution system
- Key management audit
  - FIPS-compliant key generation hardware
  - Secure distribution and storage
  - Compromise procedures
  - Key escrow, backup, archiving
  - Key destruction leaves no data
- CP and CPS audit
  - Approved, current CP
  - CP followed by all PKI parties
  - CPS complies with laws and is available
  - CPS change process and valid object identifier
- CRL/OCSP audit
  - CRL or OCSP in place and signed by CA
  - Secure CRL distribution
  - Revoked entries remain until validity end
  - Automated OCSP responses
  - Industry standards compliance
