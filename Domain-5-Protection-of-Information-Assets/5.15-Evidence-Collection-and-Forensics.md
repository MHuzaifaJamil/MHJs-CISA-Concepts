# 5.15 Evidence Collection and Forensics

> **Markers:** 📓 = in my Google Doc notes · ⭐ = frequently tested · ➕ = not in the review manual, verify · unmarked = gap to study. Numbering follows the ISACA CISA Review Manual 28th Ed.

- Proper procedures required or evidence may be unusable
- Leave environment and evidence unaltered; call specialists
### 5.15.1 Types of investigations
- Administrative investigation: HR scenarios
- Criminal investigation: beyond reasonable doubt; evidence shared with defense
- Civil investigation: preponderance of evidence; monetary damages
- Regulatory investigation: for example SEC
- Industry standards investigation
- Forensic investigation: documented chain of evidence
### 5.15.2 Types of computer forensics
- Database forensics
- Email forensics
- Mobile forensics
- Memory forensics: live analysis
- Network forensics
- Malware forensics
### 5.15.3 Phases of computer forensics
- First response
- Search and seizure
- Evidence collection
- Evidence security
- Data acquisition: electronically stored information (ESI)
- Data analysis: extraction, processing, modeling, interpretation
- Evidence assessment
- Documentation and reporting
- Expert witness testimony
### 5.15.4 Audit considerations
- Data protection
  - Protocols to preserve evidence; incident handling infrastructure
- Data acquisition
  - Transfer to controlled location; write-blocker
  - Volatile data: open ports, files, processes, logons, RAM
  - Recorded witness statements
- Imaging
  - Bit-for-bit copy, sector by sector
  - Captures residual data: deleted files, fragments
- Extraction
  - Select data from image: system, firewall, IDS logs, audit trails
- Interrogation
  - Find indicators: phone numbers, IP addresses, names
- Ingestion / normalization
  - Convert hex or binary to readable form
  - Fusion, correlation, graphing, mapping, time lining
- Reporting
  - Two reports: technical for IT, nontechnical for management
  - Accurate, understandable, defensible, unambiguous
  - Include why, how and conclusions; reservations
### 5.15.5 Computer forensic techniques
- Deleted file recovery (file carving, data carving)
- Reverse steganography: hash comparison
- Cross-drive analysis: anomaly detection
- Live analysis: volatile data; lab extraction keeps chain of custody
- Stochastic forensics: insider cases without artifacts
### 5.15.6 Computer forensics tools
- Acquisition tools: mirror-image, bit-stream backup of storage devices
- Digital evidence bags (DEBs)
  - Tag file: metadata and chain of custody
  - Index file: source, format, capture device
  - Bag file: actual evidence
- Analysis tools: file listing; TrueCrypt, Hide and Seek used by suspects
- File recovery tools: EnCase opens suspicious files
### 5.15.7 Chain of custody
- Document how evidence is handled, owned, transferred, modified
- Image system and dump memory before reboot
- Analyze copies, not original
- Record: who had access (chronological)
- Record: procedures followed
- Record: proof copies match original (checksums, timestamps)
- Booting suspect computer writes to drive
### 5.15.8 Best practices to secure digital evidence
- Prevent contamination
- Have a clear chain of custody
- Implement tamper detection: hash values
- Secure storage devices
- Keep mobile devices digitally isolated: Faraday bag, airplane mode
- Encrypt the hard drive
- Involve forensic experts
- Avoid changing device power status
- Monitor evidence transactions
- Install write-blocking software
- Incorporate other evidence: email headers, chat, websites
### Case study (ORM)
- Scenario: Spectertainment, remote staff using personal devices on VPN
- VPN risk: remote PCs at home most concerning
  - VPN does not protect remote PC from Internet attack
  - Compromised remote PC enables lateral movement
- Access control software: greatest protection at network and OS level
- Forgotten password: verify identity by challenge/response first
  - Call back after verifying extension or supervisor
- Personal devices: acceptable use policy and BYOD policy address it
- BYOD benefits: productivity, cost savings
- BYOD drawback: harder to terminate access
